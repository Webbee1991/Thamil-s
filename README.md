# Chenthamil Selvan — Digital Portfolio

Premium, responsive portfolio covering **business analysis**, **CX & business transformation**, **AI & automation**, and **project delivery**.

**Live site:** https://webbee1991.github.io/Thamil-s/

**Current version:** V7.2

The homepage highlights cross-functional problem solving and project delivery. Four featured projects include illustrative visual workflows or a conceptual dashboard wireframe; these are *not* production screenshots or quantified outcome claims. All seven CX, billing and commercial improvement areas are immediately available on mobile, with filters still supported.

## Assets and performance

- `index.html` is the single canonical entry point.
- `intex.html` redirects legacy links to the homepage.
- `portrait-source.png` preserves the existing professional photograph.
- `portrait.webp` is the web-optimized portrait generated by GitHub Actions.
- `social-preview.png` is the 1200×630 social-sharing preview generated by GitHub Actions.
- `Chenthamil_Selvan_Resume_V7_1.pdf` remains a separate linked résumé (not embedded in HTML).
- `case-study-visuals.css` and `case-study-visuals.js` provide reusable, non-confidential case-study visuals.

The publishing workflow regenerates image assets from the original portrait, commits changes if needed, and supports either branch-based or Actions-based GitHub Pages.

**Important:** V7.2 does **not** add any unverified business-impact figures. An individual LinkedIn profile link can be added when its exact URL is provided; the site currently offers a LinkedIn sharing link.
